Web Development Internship — Project Portfolio

This repository contains the projects I developed during my 8-week Web Development Internship at Next Gen Software Hub Pvt. Ltd.

About the Internship

The internship focuses on practical web development using HTML, CSS, and JavaScript. Through these projects, I practised responsive design, DOM manipulation, event handling, error handling, and Git/GitHub version control.

Technologies: HTML, CSS

- Personal introduction and about section.

- Responsive layout and navigation.

Folder: "week1-2-portfolio"

Week 3–4: Interactive To-Do List

Technologies: HTML, CSS, JavaScript

Technologies: HTML, CSS, JavaScript

How to Run the Projects

1. Clone or download this repository.
2. Open the required project folder.
3. Open its "index.html" file in a browser, or use the VS Code Live Server extension.
4. For JavaScript-based projects, keep all their associated files in the same project folder.

Learning Outcomes

- Building responsive web interfaces.
- Using JavaScript to make web pages interactive.
- Manipulating the DOM and handling user events.
- Implementing browser local storage.
- Handling errors and keyboard input.
- Managing project versions with Git and GitHub.
